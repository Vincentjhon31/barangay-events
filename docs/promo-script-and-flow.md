# Barangay Events Promo Package

## 1. Workflow Summary

Barangay Events is a Flutter-based mobile app that helps citizens, LGU staff, and administrators coordinate community activities in one place. Citizens can sign up, view the calendar, join groups, and submit or follow events. LGU staff review and publish official barangay activities, while super admins manage access and account roles. The system uses real-time updates and push notifications to keep everyone informed.

## 2. Main Process Flowchart

```mermaid
flowchart TD
    A[Citizen opens app] --> B{Has account?}
    B -- Yes --> C[Logs in]
    B -- No --> D[Creates account]
    C --> E[Views calendar and events]
    D --> E
    E --> F[Browses public or group events]
    F --> G[Joins group or views details]
    G --> H[Creates or updates an event]
    H --> I[Submits event for review]
    I --> J[LGU reviews submission]
    J --> K{Approved?}
    K -- Yes --> L[Publishes event]
    K -- No --> M[Returns for revision]
    M --> H
    L --> N[Real-time updates and notifications]
    N --> O[Citizens receive updates]

    P[LGU logs in] --> Q[Manages events and announcements]
    Q --> R[Approves or rejects submissions]
    R --> S[Publishes official barangay activities]

    T[Super Admin logs in] --> U[Manages admin accounts]
    U --> V[Creates or updates roles]
    V --> W[Controls access and system settings]
```
