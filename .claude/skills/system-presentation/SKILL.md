# System Presentation

## When to Use

- When you need to explain how the app works in a short, compelling format.
- When you want a flowchart of the main process and a presenter-friendly script.
- When preparing a promo, demo video, or stakeholder walkthrough.

## Goal

Produce a concise presentation package containing:

1. A short analysis of the system and its core workflow.
2. A flowchart showing the main process steps.
3. A 50-second or 1-minute script for a video presentation.
4. Suggested motion graphics, visuals, and on-screen text for promotion.

## Procedure

1. Review the relevant code, app structure, and documentation.
2. Identify the primary user journey and key system modules.
3. Summarize the workflow in plain language.
4. Create a simple Mermaid flowchart of the main process.
5. Write a short, sharp script with a strong opening, clear middle, and memorable ending.
6. Add motion-graphics suggestions such as screen transitions, animated icons, data flow visuals, and UI highlights.

## Output Format

- Summary: 3-5 bullet points describing the system.
- Flowchart: Mermaid code block.
- Video script: 50-60 seconds, spoken in a clear, energetic style.
- Visual ideas: 4-6 bullet points for graphics and motion.

## Quality Checklist

- Focus on the core value of the system.
- Keep the explanation easy to follow.
- Make the script feel promotional but still informative.
- Ensure the flowchart matches the described process.

## Example Prompt

Use this prompt with the skill:
'Analyze the workflow of this app, create a flowchart, and produce a 50-second promo video script with motion graphics ideas.'
